# Notebook

Un notebook per laboratorio, pubblicato prima della lezione. Ogni notebook è eseguibile dall'inizio alla fine: si eseguono le celle, si cambiano i parametri delle celle «Prova a cambiare» e si confronta con quello che ci si aspettava.

A ogni lezione: `git pull`, poi si copia il notebook in `work/` e si lavora sulla copia. `work/` è ignorata da git, quindi il pull della settimana dopo non va in conflitto; il notebook scrive i suoi file in `work/` della radice del repository ovunque sia aperto.

| notebook | laboratorio |
|---|---|
| `lab00_setup.ipynb` | Lab 0 — L'ambiente di lavoro |
| `lab01_mqtt.ipynb` | Lab 1 — TCP grezzo e MQTT |
